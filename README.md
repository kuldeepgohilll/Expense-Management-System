# Expense Management System

A full-stack web application for managing personal income, expenses, and monthly budgets. The project was developed using C#, ASP.NET Core MVC, Entity Framework Core, SQL Server LocalDB, HTML, CSS, Bootstrap, and JavaScript with Chart.js.

## Features

- User registration and login
- Secure password hashing
- Add, edit, and delete income and expense transactions
- Categorize transactions
- Select payment methods
- Set monthly budgets
- Track budget usage and remaining amount
- Dashboard showing income, expenses, balance, and budget information
- Category-wise spending visualization
- Search and filter transactions
- User-specific data management
- Form validation and responsive UI
